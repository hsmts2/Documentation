Git / GitHub 概要

初期設定

ℹ️ Git BashとPowerShellの違い

どちらもWindows上でコマンドを入力して操作する環境（シェル）
Git Bashへの切り替えはOSの変更ではなく、コマンドを解釈する環境の切り替え

git statusなどのGitコマンドは基本的に共通
ファイルの内容表示はGit Bashでcat、PowerShellでGet-Contentを使用するなど、一部のコマンドやパス表記に違い

共通コマンドは「Git Bash / PowerShell」と併記
操作手順が異なる場合のみタブで切り替え

1. Gitのインストール

Gitのバージョンを確認

Git Bash / PowerShell
git --version

Git for Windowsの公式ページから、PCのアーキテクチャに対応するインストーラーを取得
取得したファイルを開き、画面に従ってインストールを実行

出典：Git for Windowsの公式インストールページ

PowerShellを起動し、WinGetでGitをインストール

PowerShell
winget install --id Git.Git -e --source winget

インストール完了後にGit BashまたはPowerShellを起動し、バージョンを再確認

Git Bash / PowerShell
git --version

出典：Git公式：Install for Windows

2. コミットに記録する名前・メールの設定

コミットに記録する名前を設定
t_hashimotoは例示値のため、勤務先指定の名前への置き換え

Git Bash / PowerShell
git config --global user.name "t_hashimoto"

コミットに記録するメールアドレスを設定
t_hashimoto@example.comは例示値のため、勤務先指定のメールアドレスへの置き換え

Git Bash / PowerShell
git config --global user.email "t_hashimoto@example.com"

名前・メールは「誰が変更を記録したか」を示す情報であり、GitHubへのログイン設定とは別の設定

--globalは、そのPCの現在のユーザーに共通する設定範囲
PCの全ユーザー共通ではなく、リポジトリ固有の設定がある場合はそちらを優先

設定値は通常ユーザーフォルダの.gitconfigに保存され、再起動後も保持
毎回の再設定は不要で、PowerShellのユーザー名表示や過去のコミットは変更対象外

出典：Git公式：First-Time Git Setup

3. 初期ブランチ名の設定

勤務先でmainを使用する方針の場合に、新規リポジトリの初期ブランチ名を設定

Git Bash / PowerShell
git config --global init.defaultBranch main

今後git initで新しく作成するリポジトリへの適用
既存ブランチの改名や、現在のブランチの切り替えは対象外

既にmainが設定済みの場合は、再設定不要

出典：Git公式：git init

4. 使用するエディタの設定

VS Codeを使用する場合は、インストール済みでcodeコマンドが利用可能なことを確認

Git Bash / PowerShell
code --version

コミットメッセージなどの入力に使用するエディタとしてVS Codeを設定

Git Bash / PowerShell
git config --global core.editor "code --wait"

--waitは編集対象のファイルを閉じるまで待機するための指定
別のエディタを使用する場合は、そのエディタに対応する起動コマンドへ変更

出典：Git公式：Setup and Config

5. 設定結果の確認

名前、メール、初期ブランチ名、エディタのグローバル設定を確認

Git Bash / PowerShell
git config --global user.name
git config --global user.email
git config --global init.defaultBranch
git config --global core.editor

上記の例示値を設定した場合の期待結果

実行結果（例）
t_hashimoto
t_hashimoto@example.com
main
code --wait

core.editorの出力が空の場合は、グローバル設定での未設定を示す結果
別の設定や既定のエディタが使用されるため、エディタ自体の利用不可とは別の状態

読み込み元の設定ファイルと設定値を確認

Git Bash / PowerShell
git config --list --show-origin

リポジトリ固有の設定を含めて確認する場合は、対象リポジトリ内で実行

⚠️ 注意

設定一覧にはメールアドレス、業務用パス、接続先などが含まれるため、記事への掲載前に機密情報・個人情報の有無を確認

出典：Git公式：First-Time Git Setup
