Git / GitHub

Git / GitHub 概要

初期設定

1. Gitのインストール

Gitのバージョンを確認

Git Bash / PowerShell
git --version

Git for Windowsの公式ページから、インストーラーをダウンロードし実行

出典：Git for Windowsの公式インストールページ

PowerShellを起動し、WinGetでGitをインストール

PowerShell
winget install --id Git.Git -e --source winget

インストール完了後にGit BashまたはPowerShellを起動し、バージョンを再確認

Git Bash / PowerShell
git --version

出典：Git公式：Install for Windows

ℹ️ Git BashとPowerShellの違い

Git BashとPowerShellはWindows上で動作するシェルで、基本的なGitコマンドは共通する一方、ファイル操作やパス表記に違いがあり、内容表示にはそれぞれcat、Get-Contentを使用

2. コミットに記録する名前・メールの設定

コミットに記録する名前を設定（t_hashimotoは例示値のため、必要に応じて変更）

Git Bash / PowerShell
git config --global user.name "t_hashimoto"

コミットに記録するメールを設定（t_hashimoto@example.comは例示値のため、必要に応じて変更）

Git Bash / PowerShell
git config --global user.email "t_hashimoto@example.com"

名前・メールはGitHubのログイン情報ではなく、コミットの記録者情報として設定し、--globalで現在のユーザーに共通適用（リポジトリ固有の設定を優先）、通常は~/.gitconfigに保存されるため再起動後の再設定は不要

出典：Git公式：First-Time Git Setup

3. 初期ブランチ名の設定

新規リポジトリの初期ブランチ名をmainに設定（設定済みの場合は不要）

Git Bash / PowerShell
git config --global init.defaultBranch main

git initによる新規作成時に適用（既存ブランチへの影響なし）

出典：Git公式：git init

4. 使用するエディタの設定

VS Codeのcodeコマンドが利用可能か確認

Git Bash / PowerShell
code --version

Gitで使用するエディタにVS Codeを設定

Git Bash / PowerShell
git config --global core.editor "code --wait"

--waitはファイルを閉じるまで待機する指定（他のエディタは起動コマンドを変更）

出典：Git公式：Setup and Config

5. 設定結果の確認

名前、メール、初期ブランチ名、エディタのグローバル設定を確認

Git Bash / PowerShell
git config --global user.name
git config --global user.email
git config --global init.defaultBranch
git config --global core.editor
実行結果
実行結果（例）
t_hashimoto
t_hashimoto@example.com
main
code --wait

core.editorが空ならグローバル設定は未設定（別の設定や既定のエディタを使用）

読み込み元の設定ファイルと設定値を確認

Git Bash / PowerShell
git config --list --show-origin

リポジトリ固有の設定を含めて確認する場合は、対象リポジトリ内で実行

⚠️ 注意

設定一覧にはメールアドレス、業務用パス、接続先などが含まれるため、記事への掲載前に機密情報・個人情報の有無を確認

出典：Git公式：First-Time Git Setup

リポジトリの初期化とステージング

Git Bashのホームフォルダから開始し、練習用のprojectを作成してREADME.mdをステージングする手順

1. 作業フォルダの作成・移動

ホームフォルダに練習用フォルダを作成

Git Bash
mkdir project

作成したフォルダへ移動

Git Bash
cd project

2. リポジトリの初期化

現在のフォルダをGitリポジトリとして初期化

Git Bash / PowerShell
git init

履歴や設定を管理する.gitフォルダを作成（初期設定により初期ブランチ名はmain）

実行結果

ユーザー名は公開用の例示値に置き換え

実行結果（例）
Initialized empty Git repository in C:/Users/t_hashimoto/project/.git/

隠しフォルダを含む一覧を表示し、.gitの作成を確認

Git Bash
ls -la

3. README.mdの作成

Helloを記載したREADME.mdを作成（同名ファイルがある場合は上書き）

Git Bash
echo "Hello" > README.md

4. README.mdのステージング

README.mdを次のコミットに含める対象として登録

Git Bash / PowerShell
git add README.md
実行結果
実行時の警告
warning: in the working copy of 'README.md', LF will be replaced by CRLF the next time Git touches it

作業ファイルの改行コード変換に関する警告であり、今回のステージングは成功（次のgit statusで確認）

5. ステージング状態の確認

コミット対象として登録されたファイルを確認

Git Bash / PowerShell
git status
実行結果
実行結果
On branch main

No commits yet

Changes to be committed:
  (use "git rm --cached <file>..." to unstage)
        new file:   README.md

Changes to be committedはステージング済み、No commits yetはコミット未作成を示す状態
