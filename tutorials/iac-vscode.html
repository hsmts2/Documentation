拡張機能のインストール

今回のPCで導入を確認した拡張機能から、IaC・Git操作に使用するものを選定。業務PCでは組織の許可範囲で導入し、AI機能や個人アカウントとの同期は社内ルールを確認

No.拡張機能用途導入区分
1HashiCorp TerraformTerraformの入力補完・構文診断・整形Terraformで使用
2YAML（Red Hat）YAMLの編集・整形CloudFormationで使用
3PrettierTypeScriptなどの自動整形CDKで使用
4AWS ToolkitAWSプロファイル接続・リソース確認AWS操作で使用
5GitHub Pull RequestsGitHubのPR・レビュー操作GitHubを使う場合
6GitHub Actionsワークフローの編集・実行状況確認CI/CDを使う場合
7Japanese Language PackVS Codeの日本語表示任意
8Live PreviewHTML手順書をローカル表示既存導入済み・HTML編集時に便利
9Codexコードの相談・修正支援任意・業務利用の承認後

① Ctrl + Shift + Xで拡張機能を開き、下記IDで検索してインストールボタンを押下。コマンドで導入する場合は、VS Codeの統合ターミナルで必要な行のみ実行

PowerShell
code --install-extension hashicorp.terraform
code --install-extension redhat.vscode-yaml
code --install-extension esbenp.prettier-vscode
code --install-extension amazonwebservices.aws-toolkit-vscode
code --install-extension github.vscode-pull-request-github
code --install-extension github.vscode-github-actions
code --install-extension ms-ceintl.vscode-language-pack-ja

② HTML編集・AI支援が必要な場合のみ、任意の拡張機能を導入

PowerShell
code --install-extension ms-vscode.live-server
code --install-extension openai.chatgpt

③ 導入結果を確認。Amazon Qは今回の導入確認一覧には含めず、上記編集機能の利用に必須としない

PowerShell
code --list-extensions --show-versions

自動整形の設定

① Ctrl + Shift + Pを押し、Preferences: Open User Settings (JSON)を選択

② 既存の設定を消さず、次の項目を統合して保存。同じ言語の設定がある場合は重複作成せず、その中の項目を変更。以下は実際のPCで確認した整形設定

settings.json（整形部分）
{
  "[terraform]": {
    "editor.defaultFormatter": "hashicorp.terraform",
    "editor.formatOnSave": true
  },
  "[terraform-vars]": {
    "editor.defaultFormatter": "hashicorp.terraform",
    "editor.formatOnSave": true
  },
  "[typescript]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode",
    "editor.formatOnSave": true
  },
  "[yaml]": {
    "editor.defaultFormatter": "redhat.vscode-yaml"
  }
}

③ Terraform・TypeScriptはCtrl + Sで保存時に整形。YAMLはShift + Alt + Fで手動整形し、選択画面が出た場合はYAMLを選択

④ YAMLも保存時に整形したい場合は、上記の[yaml]を次に変更（任意の追加設定）

settings.jsonの[yaml]部分
"[yaml]": {
  "editor.defaultFormatter": "redhat.vscode-yaml",
  "editor.formatOnSave": true
}

整形は空白・字下げなどの統一。YAMLの誤った親子関係や、意図しないAWS設定値を自動修正するものではない。変更後は各ツールの検証を実行

統合ターミナルの使用

① Ctrl + Shift + `で新しいターミナルを開く。画面下部がPowerShellであることを確認。別ウィンドウのPowerShellやGit Bashは不要

② 実行するプロジェクトへ移動して現在位置を確認。開いている.tsや.tfファイルの場所へ自動で移動するわけではない

PowerShell
cd C:\Users\hsmts\IaC\CDK
pwd
Get-ChildItem -Force

③ ファイルを保存してからコマンドを入力。結果は同じターミナルに表示される。コマンドパレット実行の結果が見つからない場合も、この方法で確認

操作ショートカット・注意点
保存Ctrl + S
候補の表示Ctrl + Space
ドキュメントの整形Shift + Alt + F
エラー・警告を確認Ctrl + Shift + M
隠しファイルも表示PowerShellではls -Force。ls -laは使用しない

拡張機能の接続

対象操作
Terraform・YAML・Prettier編集・整形の利用にログインは不要
AWS ToolkitAWSビューから接続を選択し、SSOプロファイルiac-adminで接続。ターミナル側も--profileまたはAWS_PROFILEで指定
GitHubPRなどを使う際にGitHubへサインイン。Microsoftの設定同期アカウントとは別の用途
HCP TerraformHCP TerraformビューのLogin to HCP Terraformを押下し、APIトークンで接続後にOrganizationを選択。ブラウザログインだけでは拡張機能の接続は完了しない
CodexCodexビューで利用するアカウントへサインイン。VS CodeのGitHub・Microsoftサインインとは別

APIトークンは拡張機能の指定する入力欄へ登録し、settings.jsonやコードへ書き込まない。ローカルTerraformからAWSを操作する学習では、HCP Terraformへの接続は必須ではない
