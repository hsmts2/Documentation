Git Bash
$ echo "- 学習中: Git" >> profile.md

diff --git a/profile.md b/profile.md

+++ b/profile.md

Git Bash / PowerShell

Git Bash / PowerShell
$ git log --oneline -2
71dd282 (HEAD -> main) Udpate profile
73318e4 Initial practice files

Udpateは修正を試すための意図的な誤記。71dd282としてファイルの追記を保存

2. 修正前の位置を保存してamend

Git Bash / PowerShell
$ git branch original_main
Git Bash / PowerShell
git branch -a
* main
  original_main
Git Bash / PowerShell
$ git commit --amend -m "Update profile"
[main 638cd67] Update profile
 Date: Thu Sep 17 00:53:52 2026 +0900

Git Bash / PowerShell
$ git log --oneline -2
638cd67 (HEAD -> main) Update profile
73318e4 Initial practice files

original_mainは修正前の位置を残す目印。mainは638cd67へ移動し、Update profileというメッセージの新しいコミットへ置き換え。今回はファイル内容の変更なし

作業ファイルの変更を取り消す

1. 未ステージングの変更を確認

右側のMはワーキングツリーに未ステージングの変更あり。今回はgit addを実行していない状態

2. 変更を取り消して確認

Git Bash / PowerShell

git restoreは既定でインデックスの内容を作業ファイルへ復元。今回は練習用の行が消え、コミット済みの「学習中: Git」は保持

リモートを間違えて登録した場合

書籍のHTTPSからSSHへの変更例を、PC内の間違ったパスから正しいパスへの再登録に置き換え。最初からmainのためgit branch -M mainは省略し、別履歴の共有先へのgit push -u origin mainも未実施

1. 接続先を登録・確認

Git Bash / PowerShell
$ git remote -v

出力なし

Git Bash / PowerShell
$ git remote add origin ../02-push/wrong.git
Git Bash / PowerShell
git remote -v
origin  ../02-push/wrong.git (fetch)
origin  ../02-push/wrong.git (push)

remote addは現在のリポジトリの.git/configに接続先を登録する操作。接続確認は行わないため、存在しないwrong.gitでも登録可能

2. 重複エラーと登録の削除

Git Bash / PowerShell
$ git remote add origin ../02-push/remote.git
error: remote origin already exists.
Git Bash / PowerShell
$ git remote remove origin
Git Bash / PowerShell
git remote -v

出力なし

origin already existsは今回意図的に確認するエラー。同名のoriginが既にあるため追加できない状態。removeは手元の接続先登録だけを削除し、共有先自体は削除しない操作

3. 正しい接続先の登録・確認・片付け

Git Bash / PowerShell
$ git remote add origin ../02-push/remote.git/
Git Bash / PowerShell
git remote -v
origin  ../02-push/remote.git/ (fetch)
origin  ../02-push/remote.git/ (push)
Git Bash / PowerShell
$ git ls-remote --heads origin
4d8a764042de03661ae21c0d6380c8ee2ab14b98        refs/heads/main
Git Bash / PowerShell
$ git remote remove origin
Git Bash / PowerShell
git remote -v

出力なし

Git Bash / PowerShell
$ git status
On branch main
nothing to commit, working tree clean

ls-remoteで共有先のmainとコミットIDを確認。接続先はPC内の../02-push/remote.git/で、GitHub認証は不要。今回は登録の練習だけのためpushは未実施
