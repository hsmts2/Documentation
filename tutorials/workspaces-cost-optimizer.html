ソリューション構成と重要事項

Cost Optimizer for Amazon WorkSpacesは、WorkSpaces本体の組み込み機能ではなく、AWS Solutions Libraryから提供されるCloudFormationテンプレートで構築するソリューションです。WorkSpacesの利用時間と料金しきい値を比較し、時間課金のAUTO_STOPと月額課金のALWAYS_ONのどちらが適しているかを日次で判定する

構成図_ハブアカウント単一構成_v2.9.10

今回の構成では、東京リージョンにハブテンプレートだけをデプロイし、同一AWSアカウント内のWorkSpacesを監視します。スポークアカウントは使用しない

構成要素 役割
Amazon EventBridge 1日1回、ECSタスクを起動する
Amazon ECS／AWS Fargate WorkSpacesの利用時間集計、料金しきい値との比較、課金モード変更を実行する
Amazon DynamoDB WorkSpaceの利用状況とセッション情報を保持する
Amazon S3 日次・月次CSVレポートとS3アクセスログを保存する
CloudWatch Logs／ダッシュボード 実行ログ、対象台数、変換件数、エラーおよび処理時間を確認する

処理は、EventBridgeによる起動、ECSタスクによる利用状況取得、料金しきい値との比較、DynamoDBへの状態保存、S3へのCSV出力、CloudWatchへのログ・メトリクス出力の順に進む

項目 今回の設定 事前に理解しておく内容
Dry Run 初期構築時はYes 判定結果をレポートへ出力しますが、課金モードは変更しない
未使用WorkSpace終了 No 未使用WorkSpaceを自動終了しない
除外タグ Skip_Convert 指定したWorkSpaceを課金モード変更と終了の対象外にする
監視対象リージョン Regionsは空欄 同一アカウント内の対応リージョンを走査するため、必要に応じて対象を限定する
VPC CreateNewVPC=Yes NAT GatewayとElastic IPが作成され、継続料金が発生する

警告：日次処理を重複実行しない
本ソリューションは1日1回の利用時間計算を前提としています。EventBridgeスケジュールの直接変更や同一UTC日内のECSタスク複数実行は、請求対象時間と課金モード判定を不正確にする可能性があります。CloudFormationを構成管理の正とし、配下のリソースを個別編集しない

CloudFormationスタックを削除しても、S3バケット、DynamoDBテーブル、ECS実行ログおよびVPC Flow Logsの一部はDeletionPolicy: Retainにより残ります。削除時はデータ保持と残存料金を個別に確認する

  3. 厳密な再現性が必要な場合は、実行タスクのイメージダイジェスト

固定リリースイメージのみを使用する場合は Auto-update Container Image=No とします。ただし、同一マイナーバージョン内のセキュリティ更新を自動取得しなくなるため、更新管理方法を別途定める必要がある

更新時の確認事項

  1. 更新先バージョンを固定したAWS公式テンプレートを使用してCloudFormation変更セットを作成
  2. 置換・削除対象、ECSタスク定義の新しいリビジョン、IAM変更を確認
  3. 料金しきい値、DryRun、対象リージョンなど、引き継ぐ値と変更する値を区別
  4. 更新後に SolutionVersion、ECSタスク定義のイメージ、EventBridgeターゲットを確認
  5. 次回の日次スケジュール実行後に、ECSタスク、CloudWatch Logs、S3レポートを確認する。手動実行は、AWS Supportとお客様が例外実行の影響を確認・承認した場合に限る
