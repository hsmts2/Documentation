IAM Identity Center

① IAM Identity Centerを有効化

1. AWSマネジメントコンソールで東京リージョンを選択し、IAM Identity Centerを開いて有効にするボタンを押下

2. AWS Organizations で IAM Identity Center を有効にする画面で単一リージョンインスタンスを選択し、次の設定を確認

項目設定値
保存時の暗号化AWS 所有のキー
アクセス許可セット有効
プライマリリージョンアジアパシフィック (東京)
その他のリージョンなし

3. 有効にするボタンを押下

4. ダッシュボードで組織インスタンスの作成完了を確認し、IDソースがIdentity Center ディレクトリ、プライマリリージョンがap-northeast-1であることを確認

② アクセス許可セットを作成

1. 左メニューの許可セットを選択し、アクセス許可セットを作成ボタンを押下

2. 事前定義済みアクセス許可セットを選択し、AWS管理ポリシーからAdministratorAccessを選択して次へボタンを押下

3. 詳細を次のように設定し、次へボタンを押下

項目設定値
アクセス許可セット名AdministratorAccess
説明空欄
セッション期間1時間
リレー状態空欄
タグ追加しない

4. 設定内容を確認してアクセス許可セットを作成

5. 再びアクセス許可セットを作成ボタンを押下し、事前定義済みアクセス許可セットのReadOnlyAccessを選択して作成

6. 一覧にAdministratorAccessとReadOnlyAccessの2件が表示されることを確認

③ ユーザーを作成

1. 左メニューのユーザーを選択し、ユーザーを追加ボタンを押下

2. ユーザーの詳細を次のように入力

項目設定値
ユーザー名iac-admin
パスワードパスワードの設定手順が記載されたEメールをこのユーザーに送信
Eメールアドレス／確認招待メールを受信する同じメールアドレスを入力
名admin
姓iac
表示名iac-admin

3. 次へボタンを押下し、確認画面まで進んでユーザーを追加

④ 招待メールからパスワードを設定

1. 登録したメールアドレスでInvitation to join AWS IAM Identity Centerメールを開き、Accept invitationボタンを押下

2. New user sign up画面でユーザー名がiac-adminであることを確認

3. New passwordとConfirm passwordに同じパスワードを入力し、Set new passwordボタンを押下

⑤ AWSアカウントに割り当て

1. IAM Identity Centerの左メニューからAWS アカウントを選択

2. Root配下のAWSアカウントt_hashimotoにチェックを入れ、ユーザーまたはグループを割り当てボタンを押下

3. ユーザータブでiac-adminにチェックを入れ、次へボタンを押下

4. AdministratorAccessとReadOnlyAccessの両方にチェックを入れ、次へボタンを押下

5. 確認して送信画面で対象のアカウント、ユーザー、アクセス許可セットを確認して送信

6. AWSアカウント一覧に戻り、t_hashimotoの許可セット欄にAdministratorAccessとReadOnlyAccessが表示されることを確認

⑥ ローカルPCのAWS CLIを設定

1. WindowsのGit Bashを開き、AWS CLIのバージョンを確認

Git Bash
aws --version
実行結果
aws-cli/2.35.9 Python/3.14.5 Windows/11 exe/AMD64

2. プロファイル名をiac-adminとしてSSO設定を開始

Git Bash
aws configure sso --profile iac-admin

3. 次の値を入力。SSO start URLにはダッシュボードに表示される自分のAWSアクセスポータルURLを入力し、登録スコープはEnterで既定値を使用

入力例
SSO session name (Recommended): iac-sso
SSO start URL [None]: https://d-956*******.awsapps.com/start
SSO region [None]: ap-northeast-1
SSO registration scopes [sso:account:access]:

4. 自動で開いたブラウザでiac-adminとしてサインイン

5. MFA登録画面でAuthenticator appを選択し、Nextボタンを押下

6. 認証アプリでQRコードを読み取り、表示された6桁のコードをAuthenticator codeに入力してAssign MFAボタンを押下

7. botocore-client-iac-ssoのアクセス許可画面でアクセスを許可ボタンを押下

8. Git Bashへ戻り、対象アカウントを確認。ロールはAdministratorAccessを選択してEnter

実行結果
The only AWS account available to you is: 908*********
Using the account ID 908*********
There are 2 roles available to you.
> AdministratorAccess
  ReadOnlyAccess

9. 既定リージョンと出力形式を入力して設定を完了

入力例
Default client Region [None]: ap-northeast-1
CLI default output format (json if not specified) [None]: json

⑦ 接続先と権限を確認

1. 作成したプロファイルで接続先と使用中のロールを確認

Git Bash
aws sts get-caller-identity --profile iac-admin
実行結果
{
    "UserId": "AROA*******:iac-admin",
    "Account": "908*********",
    "Arn": "arn:aws:sts::908*********:assumed-role/AWSReservedSSO_AdministratorAccess_4c49************/iac-admin"
}

2. Accountが対象アカウントであり、ArnにAWSReservedSSO_AdministratorAccess_とiac-adminが含まれることを確認

⑧ SSOへ再ログイン

1. プロファイル名iac-adminを指定してログイン

Git Bash
aws sso login --profile iac-admin

2. ブラウザで認証とアクセス許可を完了し、Git Bashで成功メッセージを確認

実行結果
Successfully logged into Start URL: https://d-956*******.awsapps.com/start

3. セッション名を指定する場合はiac-ssoを使用。--sso-session=iac-adminでは指定したセッションが存在しないためエラーになる

指定する項目設定した名前
--profileiac-admin
--sso-sessioniac-sso
