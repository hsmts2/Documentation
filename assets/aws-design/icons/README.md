# AWS Architecture Icons

Unmodified SVG assets from the official AWS Architecture Icons package, release 07312026

Official download and usage information: https://aws.amazon.com/architecture/icons/

The hosting architecture diagrams are authored examples, not AWS-published or AWS-approved architectures

`scripts/build_hosting_architectures.py` embeds these assets in self-contained SVG diagrams

`scripts/build-acm-renewal-diagram.py` uses the same assets for the ACM renewal diagram, including Lambda, EventBridge, Secrets Manager and the Systems Manager Run Command resource icon
